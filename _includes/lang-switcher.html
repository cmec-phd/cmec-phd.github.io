{% comment %} jekyll-polyglot rewrites, at build time, any attribute value in the rendered HTML that it recognises as an internal link (href, but also plain data-* paths) to force the CURRENT active language's prefix onto it — great for same-language links (see nav.html), but it silently corrupts a deliberate link to the *other* language back to the current one, no matter how that path is embedded server-side. So no path is written into the static HTML at all here: the toggle target is computed client-side from the current URL, after the build-time rewrite has already happened. {% endcomment %}
